# Cenarios de Teste

## Autenticacao
- Usuario valido acessa o catalogo.
- Usuario com senha invalida recebe mensagem de erro.

## Carrinho
- Usuario adiciona um produto.
- Usuario remove o produto e retorna ao estado vazio.

## Checkout
- Usuario preenche nome, sobrenome e codigo postal.
- Usuario confirma o pedido e visualiza a mensagem de sucesso.

## Navegacao
- Usuario autenticado abre o menu lateral e acessa About.
